## 一、整体架构

### 1.1 生成流程全景

```
用户输入 topic
    │
    ▼
POST /ai/novel/generate_novel_outline  ──→  返回 {code:200}（异步任务已提交）
    │
    ▼
GET /app/stream_read/{sessionId}       ──→  SSE 流开始推送
    │
    ├──→ AI 思考过程文本（丢弃，不显示）
    │
    ├──→ 检测到 "base_info" ──→ 开始增量解析
    │    ├── Stage 0: base_info → total_chapters / words_per_chapter / genre / writing_style（title 静默提取不显示）
    │    ├── Stage 1: summary → story_summary
    │    ├── Stage 2: characters → 逐个角色对象
    │    ├── Stage 3: outline → 逐个章节对象
    │    └── Stage 4: done → 检测到 "power_system" 停止
    │
    ├──→ 增量解析的文本 → pendingText 队列 → 打字机逐字消费 → UI 刷新
    │
    └──→ 流结束 → 等打字机消费完 → 完整 JSON 最终校正 → idle
```

### 1.2 两种流的区别

| 特征 | 大纲流 | 章节流 |
|------|--------|--------|
| 触发接口 | `generate_novel_outline` | `generate_novel_next_chapter` |
| 流地址 | `GET /app/stream_read/{sessionId}` | 同左 |
| 数据标记 | `"base_info"` 开始 | `` ```json `` 或裸 JSON |
| 解析方式 | 阶段递进 + 正则增量匹配 | 定位 `"content"` 字段 + 逐字解码 |
| 结束标记 | `"power_system"` | `"content"` 字段闭合引号 |
| 最终校正 | 完整 JSON → `_formatOutlineResult` | 完整 JSON → 提取 content 字段 |

## 二、SSE 流接口

### 2.1 接口规格

```
GET /app/stream_read/{sessionId}
Headers:
  Accept: text/event-stream
  Cache-Control: no-cache
  token: {用户token}
```

### 2.2 响应格式特征

这**不是标准 SSE 格式**，具有以下特点：

1. **只有第一行**以 `data: ` 前缀开头，后续行均为纯文本
2. 文本中的 `\n\n` 是段落分隔，**不是** SSE 事件分隔符
3. **没有** `[DONE]` 结束标记，HTTP 连接关闭即流结束
4. 可能在流中出现错误 JSON：`{"code": 500, "message": "stream read caused exception"}`

### 2.3 首个 chunk 处理

```javascript
// 剥掉首个 chunk 的 "data: " 前缀
if (isFirstChunk) {
  isFirstChunk = false;
  if (chunk.startsWith('data: ')) chunk = chunk.substring(6);
  else if (chunk.startsWith('data:'))  chunk = chunk.substring(5);
  
  // 检查 [DONE] 信号（兼容标准 SSE）
  if (chunk.trim() === '[DONE]') return; // 流结束
}
```

### 2.4 流内错误检测

每个 chunk 到达后需检查是否为错误响应：

```javascript
const trimmed = chunk.trim();
if (trimmed.startsWith('{') && trimmed.includes('"code"')) {
  try {
    const json = JSON.parse(trimmed);
    if (json.code && json.code !== 200) {
      throw new Error(`Stream error: ${json.code} ${json.message}`);
    }
  } catch (e) {
    if (e.message.startsWith('Stream error')) throw e;
    // JSON 解析失败说明不是错误响应，正常处理
  }
}
```

## 三、大纲流解析

### 3.1 原始流数据结构

流输出的内容分为两部分：

```
...AI 中间过程文本（思考过程、验证信息，不定长，可能很长）...

{
    "base_info": {                        ← 检测到此标记开始解析
        "title": "小说名称",
        "total_chapters": 25,
        "words_per_chapter": [3500, 4500],
        "genre": "都市异能",
        "writing_style": "轻快搞笑",
        "lang": "cn",
        "narrative_pov": "第一人称",
        "pacing": "快节奏"
    },
    "story_summary": {
        "summary": "故事概要长文本..."
    },
    "characters": [
        {"name": "陆铭", "description": "角色描述...", "type": "主角"},
        {"name": "沈夜霜", "description": "角色描述...", "type": "爱人"},
        ...
    ],
    "outline": [
        {"chapter": 1, "title": "第一章标题", "description": "章节描述..."},
        {"chapter": 2, "title": "第二章标题", "description": "章节描述..."},
        ...
    ],
    "power_system": ...                   ← 检测到此标记停止解析
}
```

**关键特征**：
- JSON 是逐字/逐块流式到达的，不是一次性返回
- 流可能在任意时刻**全量重复**输出已有内容
- `"power_system"` 出现后的数据为重复数据，需忽略
- 没有 `` ```json `` 包裹标记

### 3.2 JSON 开始检测

**不使用** `` ```json `` 标记（大纲流没有），而是检测 `"base_info"` 关键字：

```
1. 每个 chunk 到达 → 追加到 rawBuf
2. 检查 rawBuf 中是否包含 "base_info"
3. 找到后 → 往前找最近的 { 作为 JSON 起点
4. 截取 { 之后的内容作为 jsonBuf，开始增量解析
```

```javascript
_processChunk(chunk) {
  if (!this.jsonStarted) {
    const marker = this.rawBuf.indexOf('"base_info"');
    if (marker !== -1) {
      this.jsonStarted = true;
      // 往前找最近的 { 作为 JSON 起点
      const jsonStart = this.rawBuf.lastIndexOf('{', marker);
      const startPos = jsonStart !== -1 ? jsonStart : marker;
      this.jsonBuf = this.rawBuf.substring(startPos);
      this._tryIncrementalParse();
    }
  } else {
    this.jsonBuf += chunk;
    this._tryIncrementalParse();
  }
}
```

### 3.3 阶段递进锁

将解析过程分为 5 个阶段，**只允许前进不允许后退**：

```
Stage 0: base_info   → 静默提取 title / 解析显示 total_chapters / words_per_chapter / genre / writing_style
Stage 1: summary     → 解析 story_summary.summary
Stage 2: characters  → 逐个解析角色对象
Stage 3: outline     → 逐个解析章节对象
Stage 4: done        → 检测到 "power_system"，停止解析
```

**阶段转换条件**（基于关键字检测，注意用 `if` 而非 `else if` 使得同一 chunk 可连续升阶）：

| 转换 | 条件 |
|------|------|
| Stage 0 → 1 | jsonBuf 中包含 `"story_summary"` 或 `"summary"` |
| Stage 1 → 2 | jsonBuf 中包含 `"characters"` |
| Stage 2 → 3 | jsonBuf 中包含 `"outline"` |
| Stage 3 → 4 | jsonBuf 中包含 `"power_system"` |

**一旦进入更高阶段，低阶段的代码不再执行**，从根本上杜绝重复数据。

### 3.4 去重机制

即使在同一阶段内，流也可能全量重新输出（服务端行为）。使用唯一标识去重：

| 数据类型 | 去重键 | 数据结构 |
|----------|--------|----------|
| 角色 | `name` | `Set<String>` |
| 章节 | `chapter` 编号 | `Set<int>` |

```javascript
// 角色去重
const name = m[1].replace(/\\"/g, '"');
if (this.parsedCharNames.has(name)) continue; // 已解析过，跳过
this.parsedCharNames.add(name);

// 章节去重
const chNum = parseInt(m[1]);
if (this.parsedOutlineChapters.has(chNum)) continue;
this.parsedOutlineChapters.add(chNum);
```

### 3.5 增量正则匹配

**核心思路**：不等待完整 JSON 对象闭合（`{...}`），只要**字段序列**匹配即可认为该条目完整。

#### 角色匹配正则

```regex
"name"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"description"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"type"\s*:\s*"((?:[^"\\]|\\.)*)"
```

→ 只要 `"type"` 值的引号闭合，即视为该角色完整。不需要 `{` 和 `}`。

#### 章节匹配正则

```regex
"chapter"\s*:\s*(\d+)\s*,\s*"title"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"description"\s*:\s*"((?:[^"\\]|\\.)*)"
```

→ 只要 `"description"` 值的引号闭合，即视为该章节完整。

#### 正则中 `((?:[^"\\]|\\.)*)` 的含义

匹配 JSON 字符串值内容（双引号之间的文本）：
- `[^"\\]` — 匹配非引号、非反斜杠的普通字符
- `\\.` — 匹配转义序列（如 `\"`, `\\`, `\n`）
- `*` — 重复 0 到多次

### 3.6 各阶段的字段级解析细节

#### Stage 0: base_info

解析 5 个字段，每个用独立 flag 控制（只解析一次）：

| 字段 | 正则 | 处理 |
|------|------|------|
| `title` | `/"title"\s*:\s*"((?:[^"\\]|\\.)*)"/` | 静默提取，**不显示**在基本信息区域，仅保存为小说名称 |
| `total_chapters` | `/"total_chapters"\s*:\s*(\d+)/` | `parseInt`，显示为"总章数：X 章" |
| `words_per_chapter` | `/"words_per_chapter"\s*:\s*\[\s*(\d+)\s*,\s*(\d+)\s*\]/` | 提取数组两个值，显示为"每章字数：min-max 字" |
| `genre` | `/"genre"\s*:\s*"((?:[^"\\]|\\.)*)"/` | 可为空，空则不输出 |
| `writing_style` | `/"writing_style"\s*:\s*"((?:[^"\\]|\\.)*)"/` | 可为空，空则不输出 |

首次进入时先输出固定 header：`"小说大纲\n\n基本信息\n"`

#### Stage 1: story_summary

```javascript
const m = s.match(/"summary"\s*:\s*"((?:[^"\\]|\\.)*)"/);
if (m) {
  const summary = m[1].replace(/\\"/g, '"').replace(/\\n/g, '\n');
  this.pendingText += `故事概要\n${summary}\n\n`;
}
```

注意 `\n` 转换：流中的 `\\n` 是 JSON 转义的换行符，需替换为真正的换行。

#### Stage 2: characters

使用全局正则 `/g` 遍历所有匹配：

```javascript
const charRegex = /"name"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"description"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"type"\s*:\s*"((?:[^"\\]|\\.)*)"/g;
```

每个匹配结果输出格式：
```
{type}
姓名：{name}
描述：{description}

```

#### Stage 3: outline

```javascript
const outRegex = /"chapter"\s*:\s*(\d+)\s*,\s*"title"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"description"\s*:\s*"((?:[^"\\]|\\.)*)"/g;
```

每个匹配结果输出格式：
```
第{chapter}章 {title}
{description}

```

### 4.3 `_decodeJsonStringIncremental` — 增量 JSON 字符串解码器

这是章节流解析的核心算法。它**逐字符扫描** raw 文本，将 JSON 字符串值（双引号内的内容）实时解码到 output buffer。

**处理的转义序列**：

| 输入 | 输出 | 说明 |
|------|------|------|
| `\n` | 换行 `\n` | 标准 JSON 转义 |
| `\t` | 制表 `\t` | 标准 JSON 转义 |
| `\r` | 回车 `\r` | 标准 JSON 转义 |
| `\"` | `"` | 转义引号 |
| `\\` | `\` | 转义反斜杠 |
| `\/` | `/` | 转义斜杠 |
| `\uXXXX` | Unicode 字符 | 4 位十六进制 |
| `\\n` | 换行 `\n` | 双重转义处理 |
| `\\t` | 制表 `\t` | 双重转义处理 |
| `\\r` | 回车 `\r` | 双重转义处理 |
| `\\"` | `"` | 双重转义处理 |
| `\\\\` | `\` | 双重转义处理 |

**终止条件**：遇到未转义的 `"` → 调用 onEnd 回调。

**不完整数据处理**：如果扫描到 raw 末尾仍未遇到闭合引号，返回当前扫描位置，等下一个 chunk 到达后从该位置继续。

```javascript
/**
 * 增量解码 JSON 字符串值
 * @param {string} raw - 完整累积的原始文本
 * @param {number} startPos - 开始扫描的位置（content 值开始引号之后）
 * @param {string[]} output - 输出 buffer（追加模式）
 * @param {Function} onEnd - 遇到闭合引号时的回调
 * @returns {number} 新的扫描位置
 */
function decodeJsonStringIncremental(raw, startPos, output, onEnd) {
  let i = startPos;
  while (i < raw.length) {
    const c = raw[i];
    
    if (c === '"') {
      // 未转义的引号 = 字符串结束
      onEnd();
      return i + 1;
    }
    
    if (c === '\\' && i + 1 < raw.length) {
      const next = raw[i + 1];
      switch (next) {
        case 'n': output.push('\n'); i += 2; continue;
        case 't': output.push('\t'); i += 2; continue;
        case 'r': output.push('\r'); i += 2; continue;
        case '"': output.push('"');  i += 2; continue;
        case '/': output.push('/');  i += 2; continue;
        case '\\':
          // 双重转义：\\n → \n, \\t → \t 等
          if (i + 2 < raw.length) {
            const third = raw[i + 2];
            if (third === 'n')  { output.push('\n'); i += 3; continue; }
            if (third === 't')  { output.push('\t'); i += 3; continue; }
            if (third === 'r')  { output.push('\r'); i += 3; continue; }
            if (third === '"')  { output.push('"');  i += 3; continue; }
            if (third === '\\') { output.push('\\'); i += 3; continue; }
          }
          output.push('\\');
          i += 2;
          continue;
        case 'u':
          // Unicode 转义 \uXXXX
          if (i + 5 < raw.length) {
            const hex = raw.substring(i + 2, i + 6);
            const code = parseInt(hex, 16);
            if (!isNaN(code)) {
              output.push(String.fromCharCode(code));
              i += 6;
              continue;
            }
          }
          return i; // 不完整的 \u，等更多数据
        default:
          output.push(next);
          i += 2;
          continue;
      }
    }
    
    if (c === '\\' && i + 1 >= raw.length) {
      return i; // 反斜杠在末尾，等更多数据
    }
    
    // 普通字符
    output.push(c);
    i++;
  }
  return i; // 未遇到闭合引号，等更多数据
}
```

## 五、打字机效果

### 5.1 架构：生产者-消费者模型

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│ SSE chunk    │────▶│ 增量解析器   │────▶│ pendingText │
│ (生产者)     │     │ (格式化文本) │     │ (待输出队列) │
└─────────────┘     └──────────────┘     └──────┬──────┘
                                                │
                                    ┌───────────▼───────────┐
                                    │ 打字机定时器 (30ms/字) │
                                    │ pendingConsumed++      │
                                    └───────────┬───────────┘
                                                │
                                    ┌───────────▼───────────┐
                                    │ displayedText          │
                                    │ = pending[0..consumed] │
                                    └───────────┬───────────┘
                                                │
                                    ┌───────────▼───────────┐
                                    │ UI 刷新               │
                                    └───────────────────────┘
```

### 5.2 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 定时器间隔 | 30ms | 每 30ms 消费一个字符 |
| 每帧字符数 | 1 | 逐字输出 |
| 输出速度 | ~33 字/秒 | 明显的打字机视觉效果 |

### 5.3 状态变量

```javascript
pendingText      = '';   // 增量解析产出的全部待输出文本（只追加不删除）
pendingConsumed  = 0;    // 已被打字机消费到的位置
displayedText    = '';   // 当前显示在 UI 上的文本 = pendingText[0..pendingConsumed]
```

### 5.4 流程时序

```
时间线 ──────────────────────────────────────────────────────→

SSE:    [chunk1]        [chunk2]                [chunk3]     [done]
           │               │                       │            │
解析:   解析出"总章数：25" 解析出"每章字数：3500-4500" 解析出角色1  完整JSON校正
           │               │                       │            │
pending: "总章数：25 章\n" +"每章字数：3500-4500 字\n" +"主角\n..."  (不变)
           │               │                       │            │
打字:   总|章|数|：|2|5    每|章|字|数|：|3|5|0|0  主|角|\n|姓   消费完→idle
```

### 5.5 Phase 状态转换

```
skeleton ──[打字机首次消费字符]──→ typing ──[流结束+打字机消费完]──→ idle
    │                                │                                │
    └──────[流出错]──────────────────┴────────[出错]─────────────→ error
```

| Phase | 含义 | UI 表现 |
|-------|------|---------|
| `skeleton` | 等待数据 | 骨架屏 |
| `typing` | 打字机输出中 | 文本逐字出现 |
| `idle` | 输出完成 | 完整文本，可交互 |
| `error` | 出错 | 错误提示 + 重试按钮 |

### 5.6 流结束处理

```javascript
_onStreamDone() {
  // 等待打字机把剩余内容消费完
  const waitTimer = setInterval(() => {
    if (pendingConsumed >= pendingText.length) {
      clearInterval(waitTimer);
      clearInterval(typewriterTimer);
      
      // 最终校正：用完整 JSON 重新格式化
      const json = extractJsonFromStream(rawBuf);
      if (json && json.base_info) {
        finalText = formatOutlineResult(json);  // 标准化替换
      } else {
        finalText = pendingText.trimEnd();       // 降级：保留增量结果
      }
      
      onComplete(finalText, { title, totalChapters });
    }
  }, 50);  // 每 50ms 检查一次
}

## 七、错误处理与断连重连

### 7.1 SSE 断连重连策略

```
SSE onError 触发
    │
    ▼
调用 getProjectDetail 查询项目状态
    │
    ├── step_status === 'DOING' → 任务仍在进行 → 重新连接 SSE
    │
    └── step_status !== 'DOING' → 任务已结束/失败
        ├── pendingText 有内容 → 保留增量结果，进入 idle
        └── pendingText 为空 → 进入 error 状态
```

### 7.2 流内错误响应

当流中收到错误 JSON（如 `{"code": 500, ...}`）时，抛出 `ApiBusinessException`，触发 onError 流程。

### 7.3 章节生成的多重降级

```
generateNextChapter 调用
    │
    ├── 成功 → 连接 SSE 流 → _startStreamingChapter
    │
    ├── 失败 (task already running) → 直接连 SSE（任务已在后台）
    │
    └── 失败 (其他) → checkStatusAndReconnect
                        ├── DOING → 连接 SSE
                        └── 非 DOING → 进入 error
```

### 7.4 章节内容后置刷新

流结束后 5 秒，异步调用 `getChapterContent` 拉取服务端完整内容，静默替换本地数据（流数据可能截断或不完整）。仅在内容有变化时才更新 UI。

## 九、JavaScript 完整示例

### 9.1 大纲流解析器（含打字机效果）

```javascript
/**
 * 大纲流式解析器 + 打字机效果
 * 
 * 使用方式：
 *   const parser = new OutlineStreamParser({
 *     onText: (displayedText) => updateUI(displayedText),
 *     onComplete: (finalText, metadata) => finalize(finalText, metadata),
 *     onError: (err) => showError(err),
 *   });
 *   parser.start(sessionId, token);
 */
class OutlineStreamParser {
  constructor({ onText, onComplete, onError }) {
    this.onText = onText;           // (displayedText: string) => void
    this.onComplete = onComplete;   // (finalText: string, metadata: {title, totalChapters}) => void
    this.onError = onError;         // (error: Error) => void

    // --- 缓冲区 ---
    this.rawBuf = '';               // 原始流文本累积
    this.jsonBuf = '';              // JSON 部分累积（从 base_info 的 { 开始）
    this.jsonStarted = false;       // 是否已检测到 JSON 开始

    // --- 打字机状态 ---
    this.pendingText = '';          // 待输出的全部文本
    this.pendingConsumed = 0;       // 已消费位置
    this.displayedText = '';        // 当前显示文本
    this.typewriterTimer = null;

    // --- 解析状态 ---
    this.parseStage = 0;            // 0=base_info, 1=summary, 2=characters, 3=outline, 4=done
    this.parsedTitle = false;
    this.parsedTotalChapters = false;
    this.parsedWordsPerChapter = false;
    this.parsedGenre = false;
    this.parsedStyle = false;
    this.parsedSummary = false;
    this.headerWritten = false;
    this.charHeaderWritten = false;
    this.outlineHeaderWritten = false;
    this.parsedCharNames = new Set();
    this.parsedOutlineChapters = new Set();

    // --- 业务数据 ---
    this.novelTitle = '小说名称';
    this.totalChapters = 0;
  }

  // =================== 启动 ===================

  async start(sessionId, token) {
    const url = `https://testapi.addaiaroot.com/app/stream_read/${sessionId}`;

    // 启动打字机定时器：每 30ms 消费 1 个字符
    this.typewriterTimer = setInterval(() => {
      if (this.pendingConsumed >= this.pendingText.length) return;
      this.pendingConsumed++;
      this.displayedText = this.pendingText.substring(0, this.pendingConsumed);
      this.onText(this.displayedText);
    }, 30);

    try {
      const response = await fetch(url, {
        headers: {
          'Accept': 'text/event-stream',
          'Cache-Control': 'no-cache',
          'token': token,
        },
      });

      if (!response.ok) throw new Error(`SSE connect failed: ${response.status}`);

      const reader = response.body.getReader();
      const decoder = new TextDecoder();
      let isFirstChunk = true;

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        let chunk = decoder.decode(value, { stream: true });

        // 剥掉首个 chunk 的 "data: " 前缀
        if (isFirstChunk) {
          isFirstChunk = false;
          if (chunk.startsWith('data: '))     chunk = chunk.substring(6);
          else if (chunk.startsWith('data:')) chunk = chunk.substring(5);
        }

        // 检测流内错误响应
        const trimmed = chunk.trim();
        if (trimmed.startsWith('{') && trimmed.includes('"code"')) {
          try {
            const errJson = JSON.parse(trimmed);
            if (errJson.code && errJson.code !== 200) {
              throw new Error(`Stream error: ${errJson.code} ${errJson.message}`);
            }
          } catch (e) {
            if (e.message.startsWith('Stream error')) throw e;
          }
        }

        this.rawBuf += chunk;
        this._processChunk(chunk);
      }

      this._onStreamDone();
    } catch (err) {
      clearInterval(this.typewriterTimer);
      this.onError(err);
    }
  }

  // =================== chunk 处理 ===================

  _processChunk(chunk) {
    if (!this.jsonStarted) {
      const marker = this.rawBuf.indexOf('"base_info"');
      if (marker !== -1) {
        this.jsonStarted = true;
        const jsonStart = this.rawBuf.lastIndexOf('{', marker);
        const startPos = jsonStart !== -1 ? jsonStart : marker;
        this.jsonBuf = this.rawBuf.substring(startPos);
        this._tryIncrementalParse();
      }
    } else {
      this.jsonBuf += chunk;
      this._tryIncrementalParse();
    }
  }

  // =================== 增量解析 ===================

  _tryIncrementalParse() {
    if (this.parseStage >= 4) return;
    const s = this.jsonBuf;

    // ===== Stage 0: base_info =====
    if (this.parseStage === 0) {
      if (!this.headerWritten) {
        this.pendingText += '小说大纲\n\n基本信息\n';
        this.headerWritten = true;
      }

      // 静默提取标题（不显示在基本信息区域，仅保存）
      if (!this.parsedTitle) {
        const m = s.match(/"title"\s*:\s*"((?:[^"\\]|\\.)*)"/);
        if (m) {
          this.novelTitle = m[1].replace(/\\"/g, '"');
          this.parsedTitle = true;
        }
      }

      if (!this.parsedTotalChapters) {
        const m = s.match(/"total_chapters"\s*:\s*(\d+)/);
        if (m) {
          this.totalChapters = parseInt(m[1]);
          this.pendingText += `总章数：${this.totalChapters} 章\n`;
          this.parsedTotalChapters = true;
        }
      }

      if (!this.parsedWordsPerChapter) {
        const m = s.match(/"words_per_chapter"\s*:\s*\[\s*(\d+)\s*,\s*(\d+)\s*\]/);
        if (m) {
          this.pendingText += `每章字数：${m[1]}-${m[2]} 字\n`;
          this.parsedWordsPerChapter = true;
        }
      }

      if (!this.parsedGenre) {
        const m = s.match(/"genre"\s*:\s*"((?:[^"\\]|\\.)*)"/);
        if (m) {
          const genre = m[1].replace(/\\"/g, '"');
          if (genre) this.pendingText += `类型标签：${genre}\n`;
          this.parsedGenre = true;
        }
      }

      if (!this.parsedStyle) {
        const m = s.match(/"writing_style"\s*:\s*"((?:[^"\\]|\\.)*)"/);
        if (m) {
          const style = m[1].replace(/\\"/g, '"');
          if (style) this.pendingText += `写作风格：${style}\n`;
          this.pendingText += '\n';
          this.parsedStyle = true;
        }
      }

      // 阶段转换
      if (s.includes('"story_summary"') || s.includes('"summary"')) {
        this.parseStage = 1;
      }
    }

    // ===== Stage 1: story_summary =====
    if (this.parseStage === 1) {
      if (!this.parsedSummary) {
        const m = s.match(/"summary"\s*:\s*"((?:[^"\\]|\\.)*)"/);
        if (m) {
          const summary = m[1].replace(/\\"/g, '"').replace(/\\n/g, '\n');
          this.pendingText += `故事概要\n${summary}\n\n`;
          this.parsedSummary = true;
        }
      }

      if (s.includes('"characters"')) {
        this.parseStage = 2;
      }
    }

    // ===== Stage 2: characters =====
    if (this.parseStage === 2) {
      const charRegex = /"name"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"description"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"type"\s*:\s*"((?:[^"\\]|\\.)*)"/g;
      let m;
      while ((m = charRegex.exec(s)) !== null) {
        const name = m[1].replace(/\\"/g, '"');
        if (this.parsedCharNames.has(name)) continue;
        this.parsedCharNames.add(name);

        if (!this.charHeaderWritten) {
          this.pendingText += '角色图鉴\n';
          this.charHeaderWritten = true;
        }
        const type = m[3].replace(/\\"/g, '"');
        const desc = m[2].replace(/\\"/g, '"').replace(/\\n/g, '\n');
        if (type) this.pendingText += `${type}\n`;
        this.pendingText += `姓名：${name}\n`;
        this.pendingText += `描述：${desc}\n\n`;
      }

      if (s.includes('"outline"')) {
        this.parseStage = 3;
      }
    }

    // ===== Stage 3: outline =====
    if (this.parseStage === 3) {
      if (s.includes('"power_system"')) {
        this.parseStage = 4;
        return;
      }

      const outRegex = /"chapter"\s*:\s*(\d+)\s*,\s*"title"\s*:\s*"((?:[^"\\]|\\.)*)"\s*,\s*"description"\s*:\s*"((?:[^"\\]|\\.)*)"/g;
      let m;
      while ((m = outRegex.exec(s)) !== null) {
        const chNum = parseInt(m[1]);
        if (this.parsedOutlineChapters.has(chNum)) continue;
        this.parsedOutlineChapters.add(chNum);

        if (!this.outlineHeaderWritten) {
          this.pendingText += '分章情节\n';
          this.outlineHeaderWritten = true;
        }
        const chTitle = m[2].replace(/\\"/g, '"');
        const chDesc = m[3].replace(/\\"/g, '"').replace(/\\n/g, '\n');
        this.pendingText += `第${chNum}章 ${chTitle}\n`;
        this.pendingText += `${chDesc}\n\n`;
      }
    }
  }

  // =================== 流结束 ===================

  _onStreamDone() {
    const waitTimer = setInterval(() => {
      if (this.pendingConsumed >= this.pendingText.length) {
        clearInterval(waitTimer);
        clearInterval(this.typewriterTimer);

        const json = this._extractJson(this.rawBuf);
        let finalText = this.pendingText.trimEnd();

        if (json && json.base_info) {
          finalText = this._formatOutlineResult(json);
          this.novelTitle = json.base_info.title || this.novelTitle;
          this.totalChapters = json.base_info.total_chapters || this.totalChapters;
        }

        this.onComplete(finalText, {
          title: this.novelTitle,
          totalChapters: this.totalChapters,
        });
      }
    }, 50);
  }

  // =================== JSON 提取 ===================

  _extractJson(rawText) {
    const cleaned = rawText.replace(/^data: ?/gm, '');

    // 优先：```json 标记
    let start = cleaned.indexOf('```json');
    if (start !== -1) {
      const jsonStart = cleaned.indexOf('{', start);
      if (jsonStart !== -1) {
        const jsonEnd = cleaned.lastIndexOf('}');
        if (jsonEnd > jsonStart) {
          try { return JSON.parse(cleaned.substring(jsonStart, jsonEnd + 1)); } catch (e) {}
        }
      }
    }

    // 回退：base_info 标记
    start = cleaned.indexOf('"base_info"');
    if (start !== -1) {
      const jsonStart = cleaned.lastIndexOf('{', start);
      const jsonEnd = cleaned.lastIndexOf('}');
      if (jsonStart !== -1 && jsonEnd > jsonStart) {
        try { return JSON.parse(cleaned.substring(jsonStart, jsonEnd + 1)); } catch (e) {}
      }
    }

    return null;
  }

  // =================== 格式化 ===================

  _formatOutlineResult(json) {
    const bi = json.base_info || {};
    const ss = json.story_summary || {};
    const chars = json.characters || [];
    const outline = json.outline || [];

    let text = '小说大纲\n\n';
    text += '基本信息\n';
    text += `总章数：${bi.total_chapters || 0} 章\n`;
    if (Array.isArray(bi.words_per_chapter) && bi.words_per_chapter.length >= 2) {
      text += `每章字数：${bi.words_per_chapter[0]}-${bi.words_per_chapter[1]} 字\n`;
    }
    if (bi.genre) text += `类型标签：${bi.genre}\n`;
    if (bi.writing_style) text += `写作风格：${bi.writing_style}\n`;
    text += '\n';

    if (ss.summary) {
      text += `故事概要\n${ss.summary}\n\n`;
    }

    if (chars.length > 0) {
      text += '角色图鉴\n';
      for (const c of chars) {
        if (c.type) text += `${c.type}\n`;
        text += `姓名：${c.name || ''}\n`;
        text += `描述：${c.description || ''}\n\n`;
      }
    }

    if (outline.length > 0) {
      text += '分章情节\n';
      for (const ch of outline) {
        text += `第${ch.chapter}章 ${ch.title || ''}\n`;
        text += `${ch.description || ''}\n\n`;
      }
    }

    return text.trimEnd();
  }

  // =================== 销毁 ===================

  destroy() {
    clearInterval(this.typewriterTimer);
  }
}

      }

      this._onStreamDone();
    } catch (err) {
      clearInterval(this.typewriterTimer);
      this.onError(err);
    }
  }

  _processChunk() {
    if (this.contentFieldDone) return;
    const raw = this.rawBuf;

    // Step 1: 检测 ```json 标记
    if (!this.jsonMarkerFound) {
      const marker = raw.indexOf('```json');
      if (marker !== -1) {
        this.jsonMarkerFound = true;
        this.scanPos = marker + 7;
        this._tryExtractTitle(raw, marker);
      }
    }

    // Step 1.5: 兼容裸 JSON（无 ```json）
    if (!this.jsonMarkerFound && !this.contentFieldStarted) {
      const contentMarker = raw.indexOf('"content"');
      if (contentMarker !== -1) {
        const colonIdx = raw.indexOf(':', contentMarker + 9);
        if (colonIdx !== -1) {
          const quoteIdx = raw.indexOf('"', colonIdx + 1);
          if (quoteIdx !== -1) {
            const braceIdx = raw.lastIndexOf('{', contentMarker);
            if (braceIdx !== -1) {
              this.jsonMarkerFound = true;
              this.contentFieldStarted = true;
              this.scanPos = quoteIdx + 1;
              this._tryExtractTitle(raw, braceIdx, contentMarker);
            }
          }
        }
      }
    }

    // Step 2: 检测 "content": "（```json 路径）
    if (this.jsonMarkerFound && !this.contentFieldStarted) {
      const contentMarker = raw.indexOf('"content"', this.scanPos);
      if (contentMarker !== -1) {
        const colonIdx = raw.indexOf(':', contentMarker + 9);
        if (colonIdx !== -1) {
          const quoteIdx = raw.indexOf('"', colonIdx + 1);
          if (quoteIdx !== -1) {
            this.contentFieldStarted = true;
            this.scanPos = quoteIdx + 1;
            if (!this.streamParsedTitle) {
              this._tryExtractTitle(raw, 0, contentMarker);
            }
          }
        }
      }
    }

    // Step 3: 增量解码 content 字符串值
    if (this.contentFieldStarted && !this.contentFieldDone) {
      this.scanPos = this._decodeJsonStringIncremental(
        raw, this.scanPos, this.contentBuf, () => {
          this.contentFieldDone = true;
        }
      );
    }
  }

  _tryExtractTitle(raw, searchStart, searchEnd) {
    const region = searchEnd !== undefined
      ? raw.substring(searchStart, searchEnd)
      : raw.substring(searchStart);
    const m = /"title"\s*:\s*"((?:[^"\\]|\\.)*)"/.exec(region);
    if (m) {
      this.streamParsedTitle = m[1].replace(/\\"/g, '"').replace(/\\\//g, '/');
      if (this.streamParsedTitle) {
        const displayTitle = `${this.chapterTitle} ${this.streamParsedTitle}`;
        this.onTitleUpdate(displayTitle);
      }
    }
  }

  _decodeJsonStringIncremental(raw, startPos, output, onEnd) {
    let i = startPos;
    while (i < raw.length) {
      const c = raw[i];
      if (c === '"') { onEnd(); return i + 1; }
      if (c === '\\' && i + 1 < raw.length) {
        const next = raw[i + 1];
        switch (next) {
          case 'n': output.push('\n'); i += 2; continue;
          case 't': output.push('\t'); i += 2; continue;
          case 'r': output.push('\r'); i += 2; continue;
          case '"': output.push('"');  i += 2; continue;
          case '/': output.push('/');  i += 2; continue;
          case '\\':
            if (i + 2 < raw.length) {
              const third = raw[i + 2];
              if ('ntr"\\'.includes(third)) {
                const map = { n: '\n', t: '\t', r: '\r', '"': '"', '\\': '\\' };
                output.push(map[third]);
                i += 3; continue;
              }
            }
            output.push('\\'); i += 2; continue;
          case 'u':
            if (i + 5 < raw.length) {
              const hex = raw.substring(i + 2, i + 6);
              const code = parseInt(hex, 16);
              if (!isNaN(code)) { output.push(String.fromCharCode(code)); i += 6; continue; }
            }
            return i;
          default: output.push(next); i += 2; continue;
        }
      }
      if (c === '\\' && i + 1 >= raw.length) return i;
      output.push(c); i++;
    }
    return i;
  }

  _onStreamDone() {
    clearInterval(this.typewriterTimer);

    const decodedContent = this.contentBuf.join('');
    const displayTitle = this.streamParsedTitle
      ? `${this.chapterTitle} ${this.streamParsedTitle}`
      : this.chapterTitle;

    if (decodedContent) {
      this.onComplete(decodedContent, displayTitle);
      return;
    }

    // 降级：尝试从完整 rawBuf 提取 JSON
    const cleaned = this.rawBuf.replace(/^data: ?/gm, '');
    let jsonStart = cleaned.indexOf('```json');
    if (jsonStart !== -1) {
      const braceStart = cleaned.indexOf('{', jsonStart);
      const braceEnd = cleaned.lastIndexOf('}');
      if (braceStart !== -1 && braceEnd > braceStart) {
        try {
          const json = JSON.parse(cleaned.substring(braceStart, braceEnd + 1));
          if (json.content) {
            this.onComplete(json.content, displayTitle);
            return;
          }
        } catch (e) {}
      }
    }

    this.onError(new Error('Failed to extract chapter content'));
  }

  destroy() {
    clearInterval(this.typewriterTimer);
  }
}
```

// =================== 大纲生成 ===================

const outlineParser = new OutlineStreamParser({
  onText: (displayedText) => {
    document.getElementById('novel-content').textContent = displayedText;

outlineParser.start('your-session-id', 'your-token');

chapterParser.start('your-session-id', 'your-token', '第1章');

window.addEventListener('beforeunload', () => {
